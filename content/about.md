**Your writing should belong to you.**

Modern publishing platforms can make writing incredibly convenient, but they can also put distance between you and the thing you're actually creating. Your work lives inside someone else's platform, behind someone else's editor, using someone else's system.

This project takes a different approach.

The engine is designed to turn ordinary Markdown files into a complete, modern website. There is no database, no proprietary publishing format and no requirement to keep your writing inside a particular service.

Your content is just files.

## Markdown in. Website out.

The engine handles the parts of publishing that are tedious:

* Rendering Markdown
* Creating article pages
* Navigation
* Layout and typography
* Responsive design
* Site configuration
* Drafting and previewing content

You concentrate on writing.

The result is a static website that can be hosted almost anywhere.

## Open source by design

The engine itself is open source because the software should be inspectable, understandable and reusable.

You can see how it works, modify it, improve it or build something completely different on top of it.

The engine is yours to experiment with.

Your publication is yours to own.

## No platform lock-in

Your articles aren't trapped inside this project.

They're Markdown files.

If you decide one day that you don't want to use this engine anymore, you still have your original writing in a format that can be opened, edited and converted by countless other tools.

That's an important part of the philosophy behind the project.

## Build your own

This isn't intended to be a single hosted blogging service.

It's an engine you can take, customise and make your own.

Change the branding. Change the configuration. Change the design. Add features. Remove features. Make it completely unrecognisable if you want.

The point isn't that everyone should have the same blog.

The point is that everyone should be able to **own their own publication**.

## Keep it simple

There is deliberately no attempt to turn this into a social network, content marketplace or complicated publishing platform.

It's a website for writing.

That's it.

Write your Markdown.

Build your site.

Publish it somewhere you control.

And keep your content.
